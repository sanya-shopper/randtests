PractRand (Doty-Humphrey, ~2010–)

Every earlier suite asks a yes/no question about a fixed amount of data. PractRand changes the question: keep reading the stream, retest at every doubling, and report how many bytes it took to break the generator. Quality becomes a number with units [Doty-Humphrey].

The unbounded-stream philosophy

PractRand's RNG_test reads raw bytes from stdin — ./mygen | RNG_test stdin64 — and applies its battery at geometrically spaced checkpoints (256 MB, 512 MB, 1 GB, …) until a test fails decisively or a cap is reached (32 TB by default). Because any real defect grows more visible with data, "first failure at 512 GB" is a meaningful, reproducible measurement that ranks generators far more finely than pass/fail at a fixed size. The Mersenne Twister, which fails two BigCrush tests, fails PractRand's binary-rank test at the quarter-terabyte scale; weak xorshift variants die in megabytes [O'Neill 2017].

The core tests

TestWhat it does
BCFNMulti-scale bit-count correlations on progressively decimated views of the stream — long-range structure
DC6Overlapping 6-bit counting — short-range pattern bias
Gap-16Gap lengths between recurrences of 16-bit values — the classical gap test, scaled up
BRankBinary matrix rank at multiple sizes — GF(2) linearity
FPFPattern-frequency testing — a sensitive general-purpose detector
mod3nChained mod-3 statistics (after gjrand) — bias invisible to power-of-two-aligned tests
TMFnAdded in 0.94 specifically to catch LCG structure cheaply

Crucially, each checkpoint runs the battery not only on the raw stream but on folded sub-streams that concentrate the low-order bits — patching the known TestU01 blind spot for defective low bits [Doty-Humphrey].

Reading the output

Every subtest yields a p-value; PractRand grades extremity against the number of tests run, escalating from "unusual" through "mildly suspicious" and "VERY SUSPICIOUS" to FAIL !!!!!!!! (more exclamation marks, more certainty). Isolated "unusual" flags are expected noise — the multiple-testing arithmetic guarantees them — and the operational rule is to watch whether an anomaly persists and sharpens at successive doublings. A real defect only ever gets worse with more data [O'Neill 2017].

Where it fits

Strengths. In practice the most sensitive general-purpose suite available; handles terabytes; native 64-bit and low-bit coverage; multithreaded; the natural complement to BigCrush — new generator papers now customarily report both, and the same piping idiom tests hash functions in counter mode.

Caveats. A pseudonymous single-author project without a peer-reviewed paper; several reference distributions are empirically calibrated rather than derived, so the fine-grained verdict grades rest on the author's calibration runs. Development has been quiet since version 0.94 (a 0.95 pre-release circulates). None of this has prevented it becoming the de facto second pillar of modern PRNG vetting — but it is engineering consensus, not reviewed statistics [Doty-Humphrey].

The data-appetite chart on the TestU01 page shows PractRand's 32 TB ceiling against the other suites — three orders of magnitude beyond BigCrush, five beyond NIST.
