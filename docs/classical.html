The classical tests

Before there were suites there was a catalog. Knuth's Seminumerical Algorithms collected the empirical tests of the 1950s and 60s into the canonical list that every later battery extends, and added the theoretical test — the spectral test — that explains why the era's most infamous generator was broken [Knuth 1997].

Knuth's empirical catalog

Throughout, the stream is either uniform reals Ui ∈ [0,1) or integer digits Yi = ⌊d·Ui⌋ in {0,…,d−1}; nearly every test ends in a chi-square or KS comparison.

TestWhat it countsWhat it catches
Equidistribution Frequency of each digit value; χ² with d−1 df Global bias toward some values
Serial Frequency of non-overlapping pairs (triples, …) over d² cells Dependence between successive values
Gap Lengths of gaps between visits to an interval; P(gap = r) = p(1−p)r Slow oscillation, clustering in ranges
Poker Pattern of matches in groups of five (pairs, three-of-a-kind, …); probabilities via Stirling numbers Too many or too few repeated values
Coupon collector Length of segment needed to see every digit value Values that arrive too regularly or too rarely
Permutation Relative orderings of t-tuples; t! categories Order biases invisible to frequency counts
Runs up / runs down Lengths of monotone runs — adjacent runs are dependent, so the plain χ² is invalid; Knuth gives a covariance-corrected statistic Local trend structure
Maximum of t V = max of each t-tuple; CDF xt, tested by KS Defects in the upper tail
Collision Balls-into-urns collisions when cells ≫ samples Sparse-regime nonuniformity, where χ² has no power
Birthday spacings Repeated spacings among sorted random "birthdays"; count is asymptotically Poisson(n³/4m) Lattice structure — lethal to lagged-Fibonacci generators [Marsaglia 1985]
Serial correlation Circular correlation between the stream and its shift First-order linear dependence

Two habits of the catalog echo through everything that followed. First, tests come in families indexed by parameters (digit count d, tuple size t, interval width p) — a generator is probed from many angles, not one. Second, results are aggregated by testing the test statistics themselves: Knuth's standard procedure is to repeat a chi-square test many times and KS-test the resulting batch, which detects both bias and suspicious over-regularity [Knuth 1997].

The birthday-spacings test deserves special mention because it became the signature test of the Diehard battery — a live demonstration runs on the Diehard page, showing a defective LCG drowning in duplicate spacings while a decent generator matches the Poisson prediction.

Overlapping patterns: the monkey tests

Counting overlapping patterns squeezes more information from the same data — successive windows share all but one symbol — but the overlap makes the counts dependent, so the naive chi-square theory fails. Correct treatment needs the distribution theory of overlapping runs and patterns: Good's corrected serial statistic [Good 1953], and the Erdős–Rényi laws governing the longest run of heads in n tosses (it grows like log₂ n, with fluctuations that never settle down) [Erdős & Rényi 1970]. Marsaglia and Zaman built this into the "monkey tests": let the generator type a long string of letters and count the k-letter words that never appear — the missing-word count for OPSO, OQSO and DNA has a known approximately normal distribution, and generators with subtle bit-level correlations miss the wrong number of words [Marsaglia & Zaman 1993]. These reappear in Diehard nearly verbatim, and the longest-run law underpins one of the NIST battery's fifteen tests.

The spectral test and RANDU

The deepest test in the catalog is not empirical at all. A linear congruential generator xk+1 = a·xk + c (mod m) does not sprinkle t-tuples of output through the unit cube — it places them on a lattice, a family of parallel hyperplanes. Marsaglia proved this is unavoidable: for any multiplicative congruential generator the t-dimensional points fall on at most (t!·m)1/t hyperplanes [Marsaglia 1968]. The spectral test computes, from a and m alone, the distance between adjacent hyperplanes in each dimension — equivalently the shortest vector in the dual lattice — and a generator is good only if that distance is small in every dimension that matters [Knuth 1997]. Knuth's verdict: all good generators pass it, all known bad ones fail it.

RANDU: the cautionary tale

IBM's RANDU (System/360, 1960s) used xk+1 = 65539·xk (mod 2³¹). The multiplier was chosen for speed: 65539 = 2¹⁶ + 3, so the multiply compiles to shifts and adds. But then, working mod 2³¹,

a² = (2¹⁶+3)² = 2³² + 6·2¹⁶ + 9 ≡ 6·(2¹⁶+3) − 9 = 6a − 9,

so every output obeys xk+2 ≡ 6·xk+1 − 9·xk (mod 2³¹). Scaled to the unit cube, every consecutive triple satisfies 9u1 − 6u2 + u3 ∈ ℤ — fifteen parallel planes, against the ≈2300 a well-chosen multiplier of that modulus could achieve. Two-dimensional plots looked fine; every three-dimensional simulation drew from fifteen slices of the cube. Knuth's epitaph: "really horrible" [Knuth 1997].

A modern echo: linearity and the Mersenne Twister

The spectral test punishes linear structure over the integers. The same idea over GF(2) — bits, with xor as addition — condemns a whole modern family. Generators whose state update is linear in the bits (Mersenne Twister, xorshift, and relatives) produce output streams in which every bit satisfies a fixed linear recurrence. Build a large 0/1 matrix from such a stream and its rank comes out too low; measure the stream's linear complexity and it is far below what randomness demands. The Mersenne Twister [Matsumoto & Nishimura 1998] — period 2¹⁹⁹³⁷−1, 623-dimensionally equidistributed, and a clean pass of Diehard — fails exactly the MatrixRank and LinearComp tests in TestU01's BigCrush, and fails them at any sample size [L'Ecuyer & Simard 2007] [Vigna 2019]. Marsaglia's 2003 xorshift proposal [Marsaglia 2003] met the same fate even faster: Panneton and L'Ecuyer showed raw xorshift fails dozens of stringent tests [Panneton & L'Ecuyer 2005]. The pattern — each generation of generators passing the last generation of tests and failing the next — is the engine that drove the suites this site reviews.
